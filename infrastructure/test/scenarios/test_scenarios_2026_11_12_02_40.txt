FuXi - Phase 3 - Frontend
Test scenarios, shredded to atomic processes.
Created: 2026-11-11 23:40 UTC
Status: CONFIRMED BY THE LEARNER ON 2026-11-12
Amended on 2026-11-12 at the Learner's request: section M moved from the Configs page to the Settings page,
under the "Update embeddings" row (M0 added), and the page background became the logo's #FCFAEE.

Every scenario has one purpose. "Given / When / Then" is used.
Phase 3 builds the React pages from the "FuXi" Claude Design canvas, their services and one small API extension.
It contains no push subscription, no notification, no Quartz.NET job and no RAG engine.
Frontend tests use Vitest and React Testing Library with a faked fetch. No test calls a real API.

Marks:
[FE]  frontend scenario, verified by a Vitest test.
[BE]  backend scenario, verified by an xUnit test against PostgreSQL.
[RV]  verified by reading the code or by running a command.
